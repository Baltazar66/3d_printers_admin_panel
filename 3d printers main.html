// Сканер 3D-принтеров // Moonraker

ОЖИДАНИЕ
Готово. В список попадают только устройства, отвечающие на порт 7125 (Moonraker).
Принтеры не обнаружены. Запустите сканирование.
Обнаружение: признаком 3D-принтера считается ответ на порту 7125 (Moonraker API). Веб-интерфейс открывается на порту 80.
Телеметрия: запрашивается через локальный прокси на этом же сервере.
Розетки: настраиваются в devices.json. Управление идёт через Tuya Cloud API. После включения розетки автоматически запускается пересканирование через rescan_after_plug_on_sec секунд (пока принтер грузит прошивку).
Диапазон по умолчанию: берётся из scan.ip_range в devices.json, но поле в интерфейсе можно менять вручную.
Камера: URL потока берётся из webcams Moonraker; fallback — http://IP/webcam/?action=stream для Crowsnest.
